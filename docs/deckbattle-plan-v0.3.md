# ローグライク・カードバトル 試作開発計画書 v0.3

2026-11-18 · チーム共有用(共有ドキュメント版: https://claude.ai/artifact/DKdcJCTTGfS8na76ivwkqf)

v0.3 は、ブランチ `feature/deckbattle-foundation` に実装された内容に合わせて書き直した版。v0.2 で決めた「使うほど育つカード」と「イベントマスのクイズ」に加えて、メンバーが足した仕組み(エリート、敵の弱点、脆弱・ジャミング、常駐ツール、使い捨てツール、解析コインと闇市、カード基地)を正式に書き込んだ。数値はすべて試作用の仮の値で、プレイテストで調整する。

> このファイルは共有ドキュメントの写し。内容を変えるときは、共有ドキュメントとこのファイルの両方を更新する。

## 1. v0.2 からの変更点

M1(1回の戦闘)・M2(成長・進化)・M3(ラン)は、ひととおり遊べる状態になった。その途中で、v0.2 では「今回やらないこと」にしていた仕組みもいくつか入った。

| 項目 | v0.2 | v0.3(今の実装) |
| --- | --- | --- |
| 進み具合 | 計画だけ | 最初からボスまで通しで遊べる(M1〜M3) |
| カード | 6種類 | 12種類(コモン6・アンコモン4・レア2)。レアは3分岐 |
| 戦闘3 | ファイアウォールAI だけ | 通常ルートかエリート(ゼロトラストゲート)を選べる |
| 敵 | 行動の予告だけ | 敵ごとに弱点があり、合う攻撃は1.5倍 |
| 状態異常 | 過熱・反撃 | 脆弱(受けるダメージ1.5倍)・ジャミング(敵の攻撃−30%)・FW貫通・常駐効果を追加 |
| 補助の仕組み | なし | 常駐ツール(レリック)6種類、使い捨てツール4種類(最大2個) |
| 補助カード→攻撃 | 決まりなし | 解析コンボ:1ターンに1回、補助カードの後に攻撃カードを使うと帯域+1 |
| イベント | 1問だけ | 最大3問の連続チャレンジ。正解するほど報酬が良くなる |
| 解析コイン・闇市 | なし | 敵を倒すとコインが出る。事前調査(選択肢を1つ消す)と闇市で使う |
| ランをまたぐ要素 | やらない | カード基地(図鑑・弱点ノート・戦績・実績)をブラウザに保存 |
| 試作用の設定 | なし | 「試用高速成長」(経験値が多く入る)。初期設定は OFF |

## 2. 企画方針と決定事項

短時間で繰り返し遊べるデッキ構築型のカードバトルを、サイバーセキュリティの世界で作る。以下は決定済み(v0.2 から変更なし)。

- **ジャンル**:ローグライク・カードバトル。ターン制。1回のランは5〜10分。
- **独自要素**:すべてのカードが1枚ずつ経験値を持ち、使うほど育つ。Lv.3 で、決めておいた進化先から好きなものを選ぶ(固定分岐型)。同じ名前のカードでも、別々の進化先にできる。
- **世界観**:プレイヤーは侵入するハッカー、敵は防御システム。カードは実在の攻撃手法と防御策で、説明文がそのまま仕組みの解説になる。
- **学習要素**:問題集(135問)をイベントマスのクイズとして出す。正解でカードが育ち、間違えた問題はカード基地の弱点ノートで復習できる。
- **レア度**:コモン/アンコモン/レア。コモンとアンコモンは2分岐、レアは3分岐。
- **参考の仕方**:既存作品はジャンルとテンポの参考にとどめる。固有のカード名・カードの一覧・アート・UI・文言・演出、初期状態の数値をそのまま使わない。
- **ターン制**:チームで決めたとおり、実時間で進む仕組みは入れない。

## 3. 1回のランの流れ(実装済み)

ミッション選択画面の「SECTOR 06 // DECK BREACH」から始まる。7マスを順番に進む。

1. 戦闘1(スキャナーbot)→ 戦闘の結果 → 進化 → 報酬
2. イベント1:脆弱性診断(クイズ最大3問)
3. 闇市:解析コインで購入するか、そのまま次へ進む
4. 戦闘2(IDSセンサー×2)→ 結果 → 進化 → 報酬
5. イベント2:パッチ適用(クイズ最大3問)
6. 戦闘3:通常ルート(ファイアウォールAI)かエリート(ゼロトラストゲート)を選ぶ → 結果 → 進化 → 報酬
7. ボス(監視AI ARGUS)→ 結果画面(勝ち・負け、育てたデッキ)

- 戦闘の結果画面では、カードごとに入った経験値、回復量、出た解析コインを見せる。
- Lv.3 に届いたカードがあると、進化先を選ぶ画面に進む。選び終わるまで次のマスに進めない。
- 報酬は、カード3枚から1枚をもらう、デッキのカード1枚を削除する、スキップの3つから選ぶ。
- 画面の上に7マスの進み具合と所持コインを出す。デッキはいつでも開ける。

## 4. 戦闘ルール

1ターンは「カードを使う → ターン終了 → 敵が予告どおり行動 → 次のターン」。

| 項目 | 設定 |
| --- | --- |
| プレイヤーの HP(回線耐久) | 最大65、開始65。ランの間は引き継ぐ |
| 帯域(エネルギー) | 毎ターン4。余った分は持ち越さない |
| ドロー | 毎ターン4枚。使わなかった手札はターン終了時に捨て札へ。手札は最大10枚 |
| 山札が尽きたとき | 捨て札をシャッフルして山札にする |
| ファイアウォール(FW) | 受けるダメージから先に引く。プレイヤーのターン開始時に0に戻る |
| 初期デッキ(10枚) | SSH辞書攻撃4、ファイアウォール4、ポートスキャン1、セッションハイジャック1 |
| 初期の使い捨てツール | 緊急パッチ1個 |
| 勝利 | 敵を全部倒す |
| 敗北 | HP が0以下でラン終了 |
| 戦闘の後の回復 | 通常の戦闘に勝つと HP を最大の10%(6)回復。ボスは回復なし |

- 敵が複数いるときは、攻撃カードを選んでから対象の敵をクリックする。全体攻撃は対象を選ばない。
- 敵の行動は1つずつ演出して見せる(攻撃の光、ダメージの数字、効果音)。再生中は操作できない。

## 5. カードの成長・進化ルール

| 状態 | 条件 | 処理 |
| --- | --- | --- |
| Lv.1 | はじめ | 基本の効果 |
| Lv.2 | 累計経験値 2 | 戦闘・イベントの後に自動で強化 |
| Lv.3 | 累計経験値 5 | 決めておいた進化先から1つ選んで最終進化 |

経験値の入り方:

| 場面 | 経験値 |
| --- | --- |
| 通常の戦闘 | その戦闘で使ったカードに「使った回数 + 1」。ただし1枚あたり最大3 |
| エリート戦 | 上の値の2倍(最大6) |
| イベント1問目に正解 | 好きなカード1枚に +2 |
| 試用高速成長が ON のとき | 戦闘は「使った回数×3 + 2」、クイズは +5 |

その他の決まり:

- 戦闘中は使った回数を数えるだけ。レベルアップと進化は戦闘の後とイベントの後にまとめて行う。
- 同じ名前のカードも、1枚ずつの個体 ID で経験値を管理する。
- 進化はランの間だけ続く。選び直しはできない。
- イベントで経験値を渡すカードを選ぶときは、「選ぶと Lv.2 に強化」「選ぶと Lv.3 分岐進化」のように結果を先に見せる(進化プレビュー)。

## 6. カード(12種類)

EN = 帯域、FW = ファイアウォール。「貫通」は敵の FW を無視する。

| カード | レア度 | Lv.1 | Lv.2 | Lv.3 の進化先 |
| --- | --- | --- | --- | --- |
| SSH辞書攻撃 | コモン | 1EN/6ダメージ | 9ダメージ | 総当たり連打:1EN/4×3 ・ 認証突破:2EN/18 |
| ファイアウォール | コモン | 1EN/FW5 | FW8 | 多層防御:1EN/FW12 ・ リバーストラップ:1EN/FW7+反撃5 |
| DDoSフラッド | コモン | 1EN/7ダメージ | 10ダメージ | ボットネット:2EN/敵全体12 ・ 過負荷:1EN/8+過熱4 |
| ポートスキャン | コモン | 0EN/1枚引く | 2枚引く | 全ポート走査:1EN/2枚引く+帯域1 ・ 脆弱性特定:1EN/次の攻撃+8 |
| SQLインジェクション | コモン | 1EN/貫通5 | 貫通8+脆弱2T | UNION抽出:1EN/貫通6×2+脆弱2T ・ ブラインドSQLi:1EN/貫通8+過熱3+脆弱2T |
| WAFルール適用 | コモン | 1EN/FW4+1枚引く | FW7+1枚引く | 厳格フィルタ:1EN/FW10+1枚引く ・ 許可リスト最適化:1EN/FW6+1枚引く+次のカード−1EN |
| セッションハイジャック | アンコモン | 1EN/5ダメージ | 7ダメージ | トークン窃取:1EN/8+HP3回復 ・ 権限奪取:1EN/6+1枚引く |
| スクリプト自動化 | アンコモン | 1EN/次の攻撃+3 | 次の攻撃+5 | 並列実行:1EN/次の攻撃カードを2回発動 ・ マクロ化:0EN/1枚引く+次のカード−1EN |
| ARPスプーフィング | アンコモン | 1EN/敵全体4+次の攻撃+3+ジャミング1T | 敵全体6+次の攻撃+4+ジャミング2T | 中間者攻撃:1EN/敵全体8+次の攻撃+6 ・ ブロードキャスト嵐:2EN/敵全体13 |
| ハニーポット展開 | アンコモン | 1EN/FW5+反撃4 | FW7+反撃6 | ミラー罠:1EN/FW9+反撃9 ・ タールピット:1EN/FW8+反撃5+敵1体に過熱4 |
| ゼロデイ攻撃 | レア | 2EN/貫通14 | 貫通20 | RCE特化型:2EN/貫通28 ・ ワーム拡散:2EN/敵全体に貫通18 ・ エクスプロイト連鎖:0EN/貫通14+2枚引く |
| バックドア常駐 | レア | 1EN/戦闘中、毎ターンFW+3 | 毎ターンFW+5 | Root権限常駐:1EN/毎ターン帯域+1+1枚引く ・ C2ビーコン:1EN/毎ターン次の攻撃+4・ドロー+1 ・ ステルス防壁:1EN/毎ターンFW+8 |

- 敵が入れてくる「ノイズ」は使えないカードで、戦闘が終わるとデッキから消える。
- 報酬に出るのは12種類すべて。エリートに勝ったときは、レア1枚が必ず入る。
- 拡張目標:最終40種類(コモン20・アンコモン12・レア8)。

## 7. カードの組み合わせと状態異常の決まり

実装もテストもこの表を基準にする。

| 対象 | 決まり |
| --- | --- |
| 「次の攻撃+N」 | 次に使う攻撃カード1枚に乗る。複数回攻撃なら各回に、全体攻撃なら各敵に加算。重ねると合計。使ったら消える。使わなければ次のターンにも残る |
| 「次の攻撃カードを2回発動」 | 次の攻撃カード1枚の効果を丸ごと2回。+N は2回ともに乗る。経験値は使った1回分だけ |
| 「次のカード−1EN」 | 次に使うカード1枚(種類を問わない)。コストは0未満にならない |
| 解析コンボ | 1ターンに1回、補助カードを使った後に攻撃カードを使うと帯域+1 |
| 敵の弱点 | 弱点に合う攻撃(連撃=2回以上、貫通、過熱付き、全体)は1.5倍 |
| 脆弱 NT | 敵が受けるダメージ1.5倍。敵のターンの終わりに1減る。対象を選ぶカードはその敵だけに付き、先に倒した敵には付かない |
| ジャミング NT | 敵の攻撃ダメージ−30%(予告の数字にも反映)。敵のターンの終わりに1減る |
| 貫通 | 敵の FW を無視して HP に入る |
| 過熱 N | 敵のターン終了時に N ダメージ(FW を無視)。3ターン続く。重ねると N を足し、残りターンは3に戻る |
| 反撃 N | 次に受ける攻撃1回で、攻撃してきた敵に N ダメージ。FW で全部防いでも発動する |
| 常駐効果 | バックドア常駐で得た効果は、その戦闘の間ずっと毎ターン開始時に入る |
| 回復 | 最大 HP を超えない |

倍率は重なる。弱点(1.5倍)と脆弱(1.5倍)が両方かかると2.25倍になる。

## 8. 敵

敵は次のターンの行動を必ず予告し、予告どおりに動く。行動は表の順に繰り返す。

| 戦闘 | 敵 | HP | 弱点 | 行動の順番 |
| --- | --- | --- | --- | --- |
| 1 | スキャナーbot | 42 | 過熱 | 攻撃9 → FW9 → 攻撃12 |
| 2 | IDSセンサー ×2 | 各32 | 貫通 | 攻撃8×2 → 検知(次のターンの帯域−1)。2体は1ターンずらして動く |
| 3 通常 | ファイアウォールAI | 80 | 貫通 | FW20+攻撃10 → 強化(攻撃+3、戦闘中ずっと) → 攻撃24 |
| 3 エリート | ゼロトラストゲート | 124 | 連撃 | FW24+攻撃14 → 検知 → 攻撃28 |
| ボス | 監視AI ARGUS | 240 | 貫通 | HP 半分まで:攻撃20 → FW24 → ノイズ2枚。HP 半分以下:攻撃14×2 → 攻撃36 → ノイズ2枚 |

2026-11-19 にシミュレーション(条件ごとに400ラン)で調整した値。最初の数値(戦闘1が HP28、ボスが HP120)では、カードを適当な順に出すだけでも勝率100%だったため、敵の HP と攻撃力をおよそ2倍(戦闘1だけ1.5倍)にした。調整後の目安は次のとおり。

| 条件 | 勝率 | ボス戦のターン数 |
| --- | --- | --- |
| 上手いプレイ(高速成長 OFF・クイズ正答率70%) | 90% | 約8 |
| 上手いプレイ・クイズ正答率40% | 82% | 約8 |
| カードを適当な順に出す | 54% | 約9 |

数値はボットでの目安なので、人が遊んで最終的に決める。

- 予告は敵の頭の上に「⚔ 10」「🛡 12」「☣ ×2」のように出す。弱点・脆弱・ジャミング・過熱は敵の下に印で出す。
- 対象を選んでいるとき、弱点に合うカードなら「WEAK ×1.5」と出す。
- エリートに勝つと、経験値2倍、報酬にレア1枚が確定、解析コイン1枚が確定。

## 9. イベントマス(クイズ)

問題集から3択を出す。1問正解するごとに、さらに次の問題に挑むか、報酬を確定して進むかを選べる(最大3問)。

| | イベント1:脆弱性診断 | イベント2:パッチ適用 |
| --- | --- | --- |
| 出題 | TYPE A(攻撃手法の特定) | TYPE B(設定・コードの不備を見つける) |
| 1問目に正解 | 好きなカード1枚に経験値 +2 | 同じ |
| 2問目に正解 | HP10回復、カード1枚を追加、カード1枚を削除から1つ | 同じ |
| 3問目に正解 | 常駐ツールかレアカード | 同じ |
| 間違えたら | HP −5、イベント終了 | ペナルティなし、イベント終了 |

- 正解・不正解のどちらでも、解説と対策を見せる。
- 解析コインを1枚使うと「事前調査」ができ、関係のないダミーの選択肢を1つ消して2択にできる。
- 1回のランで同じ問題は出さない。間違えた問題は弱点ノートに記録される。
- TYPE C(攻撃コマンドの選択)は難しめなので使わない。

## 10. 補助の仕組み

### 常駐ツール(レリック)

一度手に入れると、その後の戦闘でずっと効く。イベント3問目の報酬か闇市で手に入る。

| 名前 | 効果 |
| --- | --- |
| 暗号化VPN | 毎ターン開始時に FW+3 |
| 自動スクレイパー | 毎ターン開始時に「次の攻撃+3」 |
| パケットキャッシュ | 毎ターンのドロー +1 |
| ゼロトラスト鍵 | 毎ターンの帯域 +1 |
| 適応型フィルター | 解析コンボが発動すると、帯域に加えて FW+3 |
| 証跡ラボ | 通常成長時、イベント1問目の正解報酬が同じカードに経験値 +3 になる |

闇市で買った常駐ツールは、その後のマスで効果を発揮する。

### 使い捨てツール

戦闘中に帯域0で使える。最大2個まで持てる。最初に緊急パッチを1個持っている。

| 名前 | 効果 |
| --- | --- |
| 緊急パッチ | HP を12回復 |
| 帯域ブースト | このターンの帯域 +2 |
| ノイズ破棄 | 手札のノイズをすべて消し、2枚引く |
| ジャミング波 | 敵全体に脆弱2T とジャミング2T |

### 解析コインと闇市

- 通常の戦闘では、倒した敵1体ごとに20%でコインが1枚出る。エリートは1枚確定。
- ランは解析コイン2枚で始まる。弱点ノートの復習ボーナスがある場合は加算する。
- コインはイベントの事前調査(1枚)と、3マス目の闇市で使える。

| 闇市の品物 | コイン |
| --- | --- |
| HP+12回復 | 1枚 |
| 使い捨てツール(2種類から選ぶ) | 1枚 |
| デッキのカード1枚を削除 | 2枚 |
| 常駐ツール | 3枚 |

## 11. カード基地(ランをまたいで残るもの)

ミッション選択画面の「🎴 カード基地」から開く。ブラウザ(localStorage)に保存され、ランをやり直しても消えない。ランそのものは保存しないので、読み込み直すとランは最初からになる。

- **図鑑**:出会ったカード・敵・解放した進化先
- **弱点ノート**:イベントで間違えた問題の復習。正解すると、次のランの開始時に解析コイン+1(最大3枚まで貯まる)
- **戦績**:プレイ回数、クリア回数、エリート撃破数、クイズの正解数、最高連続正解
- **実績**(6個):ARGUS 撃破、強敵突破、連続診断パーフェクト(3問連続正解)、進化の探求者(進化先を5種類解放)、ツール収集家(12種類すべてを図鑑に登録)、弱点克服(復習で1問正解)
