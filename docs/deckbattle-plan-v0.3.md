2026-11-18 · チーム共有用(共有ドキュメント版: https://claude.ai/artifact/DKdcJCTTGfS8na76ivwkqf)

v0.3 は、ブランチ `feature/deckbattle-foundation` に実装された内容に合わせて書き直した版(2026-11-19 にカード40種類・バックエンド保存まで反映)。v0.2 で決めた「使うほど育つカード」と「イベントマスのクイズ」に加えて、メンバーが足した仕組み(エリート、敵の弱点、脆弱・ジャミング、常駐ツール、使い捨てツール、解析コインと闇市、カード基地)を正式に書き込んだ。数値はすべて試作用の仮の値で、プレイテストで調整する。

## 1. v0.2 からの変更点

M1(1回の戦闘)・M2(成長・進化)・M3(ラン)は、ひととおり遊べる状態になった。その途中で、v0.2 では「今回やらないこと」にしていた仕組みもいくつか入った。

| 項目 | v0.2 | v0.3(今の実装) |
| --- | --- | --- |
| 進み具合 | 計画だけ | 最初からボスまで通しで遊べる(M1〜M3) |
| カード | 6種類 | 40種類(コモン20・アンコモン12・レア8)。レアは3分岐。カードごとに絵(SVG)がある |
| 強敵 | なし | マップの強敵マス(ゼロトラストゲート)。通るかどうかを道の選び方で決める |
| 敵 | 行動の予告だけ | 敵ごとに弱点があり、合う攻撃は1.5倍 |
| 状態異常 | 過熱・反撃 | 脆弱(受けるダメージ1.5倍)・ジャミング(敵の攻撃−30%)・FW貫通・常駐効果を追加 |
| マス | 6マス | 分岐マップ(12段＋ボス)。起動ノードで強化を選び、道を選んで進む |
| 初期ビルド | なし | 4種類から選ぶ(HP・デッキ・最初の常駐ツールが違う) |

## 2. 企画方針と決定事項

短時間で繰り返し遊べるデッキ構築型のカードバトルを、サイバーセキュリティの世界で作る。以下は決定済み(v0.2 から変更なし)。

- **ジャンル**:ローグライク・カードバトル。ターン制。分岐マップ(13段)での所要時間はプレイテストで測る。
- **独自要素**:すべてのカードが1枚ずつ経験値を持ち、使うほど育つ。Lv.3 で、決めておいた進化先から好きなものを選ぶ(固定分岐型)。同じ名前のカードでも、別々の進化先にできる。
- **世界観**:プレイヤーは侵入するハッカー、敵は防御システム。カードは実在の攻撃手法と防御策で、説明文がそのまま仕組みの解説になる。
- **学習要素**:問題集(135問)をイベントマスのクイズとして出す。正解でカードが育ち、間違えた問題はカード基地の弱点ノートで復習できる。
- **レア度**:コモン/アンコモン/レア。コモンとアンコモンは2分岐、レアは3分岐。
- **参考の仕方**:既存作品はジャンルとテンポの参考にとどめる。固有のカード名・カードの一覧・アート・UI・文言・演出、初期状態の数値をそのまま使わない。
- **ターン制**:チームで決めたとおり、実時間で進む仕組みは入れない。

## 3. 1回のランの流れ(実装済み)

ミッション選択画面の「OPERATION // DECK BREACH」から始まる。最初に初期ビルドと高難度レベルを選び(10章)、**分岐マップ**を下から上へ進む。マスを終えるたびにマップが出て、線でつながった次のマスから行き先を選ぶ。

### マップの形(`frontend/src/game/deckbattle/map.ts`)

- 12段＋ボスの13段。横は7列、道は5本。毎回ランダムに作るが、同じ種なら同じマップになる。
- 1段目は**起動ノード**(1つだけ)。出発前の強化を3つから1つ選ぶ(常駐ツールを1つ・使い捨てツールを補充・最大HP+8・解析コイン+3・レアカードを1枚 のうち3つが出る)。今後、常駐ツールや使い捨てツールにあたるものを増やすときは、ここの候補に足す。
- 道は隣の列までしか動かず、線は交差しない。8段目より上では道が中央に寄り、最後は**1体のボス**に全部の道が集まる。

| 段 | 役割 | 出るマス |
| --- | --- | --- |
| 1 | 起動 | 起動ノード(1つ) |
| 2〜4 | 序盤 | 戦闘・クイズ(脆弱性診断)・ハプニング。2段目の戦闘はスキャナーbot |
| 5〜6 | 中盤 | 戦闘・クイズ・ハプニング・強敵(ゼロトラストゲート)・休憩 |
| 7 | 補給 | 全部が闇市(どの道でも必ず寄れる) |
| 8〜11 | 終盤 | 戦闘・クイズ(パッチ適用)・ハプニング・強敵(ゼロトラストゲート+スキャナーbot)・休憩。11段目は休憩なし |
| 12 | 休憩 | 全部が休憩(ボス前の準備) |
| 13 | ボス | 監視AI ARGUS(1体) |

- 戦闘の敵は段で決まる:序盤はスキャナーbot か IDSセンサー×2、中盤はスキャナーbot+IDSセンサー か ファイアウォールAI、終盤はファイアウォールAI+スキャナーbot か ファイアウォールAI+IDSセンサー。
- どの道を通っても守られる決まり:休憩・強敵は続けて出ない、戦闘は3回続かない、闇市の段より前にクイズを1回は通る(学習の要素を必ず入れる)。
- 決まりは `frontend/tests/map.test.mjs` で、200通りのマップの全部の道について確かめている。

### 画面

- マスを終えると、マップの画面に戻る。光っているマスを選ぶと、そのマスに入る。
- 上のバーに「FLOOR ◯/13」と「マップを見る」ボタンを出す。戦闘中などでも、見るだけのマップを開ける。
- 戦闘の結果画面では、カードごとに入った経験値、回復量、出た解析コインを見せる。
- Lv.3 に届いたカードがあると、進化先を選ぶ画面に進む。選び終わるまで次のマスに進めない。
- 報酬は、カード3枚から1枚をもらう、デッキのカード1枚を削除する、スキップの3つから選ぶ。

## 4. 戦闘ルール

1ターンは「カードを使う → ターン終了 → 敵が予告どおり行動 → 次のターン」。

| 項目 | 設定 |
| --- | --- |
| プレイヤーの HP(回線耐久) | 最大 HP は初期ビルドで60〜75(高難度Lv.3以上は−10)。ランの間は引き継ぐ |
| 帯域(エネルギー) | 毎ターン3。余った分は持ち越さない |
| ドロー | 毎ターン5枚(帯域3より多く引くので、毎ターン出すカードを選ぶ)。使わなかった手札はターン終了時に捨て札へ。手札は最大10枚 |
| 山札が尽きたとき | 捨て札をシャッフルして山札にする |
| ファイアウォール(FW) | 受けるダメージから先に引く。プレイヤーのターン開始時に0に戻る |
| 初期デッキ(10枚) | 初期ビルドで決まる(標準侵入者は SSH辞書攻撃4、ファイアウォール4、ポートスキャン1、セッションハイジャック1) |
| 初期の使い捨てツール | 初期ビルドで決まる(標準侵入者は緊急パッチ1個) |
| 勝利 | 敵を全部倒す |
| 敗北 | HP が0以下でラン終了 |
| 戦闘の後の回復 | 通常の戦闘に勝つと HP を最大の10%(6)回復。ボスは回復なし |

- 敵が複数いるときは、攻撃カードを選んでから対象の敵をクリックする。全体攻撃は対象を選ばない。
- 敵の行動は1つずつ演出して見せる(攻撃の光、ダメージの数字、効果音)。再生中は操作できない。

## 5. カードの成長・進化ルール

| 状態 | 条件 | 処理 |
| --- | --- | --- |
| Lv.1 | はじめ | 基本の効果 |
| Lv.2 | 累計経験値 2 | 戦闘・イベントの後に自動で強化 |
| Lv.3 | 累計経験値 5 | 決めておいた進化先から1つ選んで最終進化 |

経験値の入り方:

| 場面 | 経験値 |
| --- | --- |
| 通常の戦闘 | その戦闘で使ったカードに「使った回数 + 1」。ただし1枚あたり最大3 |
| エリート戦 | 上の値の2倍(最大6) |
| イベント1問目に正解 | 好きなカード1枚に +2 |
| 試用高速成長が ON のとき | 戦闘は「使った回数×3 + 2」、クイズは +5 |

その他の決まり:

- 戦闘中は使った回数を数えるだけ。レベルアップと進化は戦闘の後とイベントの後にまとめて行う。
- 同じ名前のカードも、1枚ずつの個体 ID で経験値を管理する。
- 進化はランの間だけ続く。選び直しはできない。
- イベントで経験値を渡すカードを選ぶときは、「選ぶと Lv.2 に強化」「選ぶと Lv.3 分岐進化」のように結果を先に見せる(進化プレビュー)。

## 7. カードの組み合わせと状態異常の決まり

実装もテストもこの表を基準にする。

| 対象 | 決まり |
| --- | --- |
| 「次の攻撃+N」 | 次に使う攻撃カード1枚に乗る。複数回攻撃なら各回に、全体攻撃なら各敵に加算。重ねると合計。使ったら消える。使わなければ次のターンにも残る |
| 「次の攻撃カードを2回発動」 | 次の攻撃カード1枚の効果を丸ごと2回。+N は2回ともに乗る。経験値は使った1回分だけ |
| 「次のカード−1EN」 | 次に使うカード1枚(種類を問わない)。コストは0未満にならない |
| 解析コンボ | 1ターンに1回、補助カードを使った後に攻撃カードを使うと帯域+1 |
| 敵の弱点 | 弱点に合う攻撃(連撃=2回以上、貫通、過熱付き、全体)は1.5倍 |
| 脆弱 NT | 敵が受けるダメージ1.5倍。敵のターンの終わりに1減る。対象を選ぶカードはその敵だけに付き、先に倒した敵には付かない |
| ジャミング NT | 敵の攻撃ダメージ−30%(予告の数字にも反映)。敵のターンの終わりに1減る |
| 貫通 | 敵の FW を無視して HP に入る |
| 過熱 N | 敵のターン終了時に N ダメージ(FW を無視)。3ターン続く。重ねると N を足し、残りターンは3に戻る |
| 反撃 N | 次に受ける攻撃1回で、攻撃してきた敵に N ダメージ。FW で全部防いでも発動する |
| 常駐効果 | バックドア常駐などで得た効果は、その戦闘の間ずっと毎ターン開始時に入る |
| FWでダメージ | 今の自分の FW の量(×倍率)をダメージにする。「次の攻撃+N」も乗る。自分の FW は減らない |
| FWを2倍 | 今の自分の FW を2倍にする |
| 敵のFWを破壊・奪う | 敵の FW を0にする。「奪う」カードは、その分を自分の FW に足す |
| 状態異常なら追加 | 敵が過熱・脆弱・ジャミングのどれかなら、追加ダメージが入る |
| 過熱を即時発動 | 敵に付いている過熱の量(×倍率)のダメージを今すぐ与える(FW を無視)。過熱は減らない |
| 手札の枚数でダメージ | カードを使ったあとに残っている手札の枚数 × N のダメージ |
| ノイズの一掃 | 手札・山札・捨て札のノイズをすべて消し、消した枚数に応じて FW・敵全体へのダメージ(FW を無視)・ドローを得る |
| 攻撃強化の解除 | 敵の攻撃力の上乗せ(「強化」で増えた分)を0に戻す |
| 自分のHPを削る | 自分の HP が減る。ただし1は残る |
| 回復 | 最大 HP を超えない |

倍率は重なる。弱点(1.5倍)と脆弱(1.5倍)が両方かかると2.25倍になる。弱点の1.5倍は普通のダメージだけにかかり、「FWでダメージ」「手札の枚数でダメージ」などの特別なダメージにはかからない(脆弱はどれにもかかる)。

## 8. 敵

敵は次のターンの行動を必ず予告し、予告どおりに動く。行動は表の順に繰り返す。

| 戦闘 | 敵 | HP | 弱点 | 行動の順番 |
| --- | --- | --- | --- | --- |
| 1 | スキャナーbot | 42 | 過熱 | 攻撃7 → FW9 → 攻撃10 |
| 2 | IDSセンサー ×2 | 各32 | 貫通 | 攻撃6×2 → 検知(次のターンの帯域−1)。2体は1ターンずらして動く |
| 3 通常 | ファイアウォールAI | 80 | 貫通 | FW20+攻撃8 → 強化(攻撃+3、戦闘中ずっと) → 攻撃18 |
| 3 エリート | ゼロトラストゲート | 124 | 連撃 | FW24+攻撃10 → 検知 → 攻撃21 |
| ボス | 監視AI ARGUS | 240 | 貫通 | HP 半分まで:攻撃15 → FW24 → ノイズ2枚。HP 半分以下:攻撃10×2 → 攻撃28 → ノイズ2枚 |

2026-11-19 にシミュレーション(条件ごとに400ラン)で調整した値。最初の数値(戦闘1が HP28、ボスが HP120)では、カードを適当な順に出すだけでも勝率100%だったため、敵の HP と攻撃力をおよそ2倍(戦闘1だけ1.5倍)にした。

2026-11-20 に、毎ターンのドローを4枚から5枚にし、敵の HP を1.2倍にした。4枚引きでは手札を全部出せてしまうターンが序盤(1〜6マス)で62%、後半で35%あり、選ぶ場面がなかったため。5枚引きにすると23%・10%に減る。ドローが増えて強くなる分は、敵の HP で戻した(攻撃力で戻すと、適当に遊ぶ人の勝率が下がりすぎた)。帯域を3に減らす案は、このときは適当に遊ぶ人の勝率が16%まで落ちるので見送った。

2026-11-21 に、帯域を4から3にした(元にしたゲームと同じ「帯域3・5枚引き」)。手札を全部出せてしまうターンは序盤・後半とも1〜3%になり、ほぼ毎ターン出すカードを選ぶ。帯域3では防御まで手が回らず難しくなりすぎるので、敵の HP を1.2倍にする前の値に戻し、敵の攻撃力を約0.76倍にした(表の数値)。

2026-11-21 に、決まった16マスの道をやめて分岐マップ(3章)にした。1回のランで通るマスは13になり、戦闘は約4回・強敵は約1回に減った(自分のターンは約32回)。

今の目安(分岐マップ・標準の初期ビルド・条件ごとに300ラン。上手いボットは HP を見て道を選び、適当なボットはランダムに選ぶ)は次のとおり。

| 条件 | 勝率 |
| --- | --- |
| 上手いプレイ(高速成長 OFF・クイズ正答率70%) | 99% |
| カードを適当な順に出し、道もランダムに選ぶ | 53% |
| 上手いプレイ・高難度 Lv.3 | 78% |
| 上手いプレイ・高難度 Lv.5 | 62% |

数値はボットでの目安なので、人が遊んで最終的に決める。

- 予告は敵の頭の上に「⚔ 10」「🛡 12」「☣ ×2」のように出す。弱点・脆弱・ジャミング・過熱は敵の下に印で出す。
- 対象を選んでいるとき、弱点に合うカードなら「WEAK ×1.5」と出す。
- 強敵マスで勝つと、経験値2倍、報酬にレア1枚が確定、解析コイン1枚が確定。

## 9. イベントマス(クイズ)

問題集から3択を出す。1問正解するごとに、さらに次の問題に挑むか、報酬を確定して進むかを選べる(最大3問)。

| | イベント1:脆弱性診断 | イベント2:パッチ適用 |
| --- | --- | --- |
| 出題 | TYPE A(攻撃手法の特定) | TYPE B(設定・コードの不備を見つける) |
| 1問目に正解 | 好きなカード1枚に経験値 +2 | 同じ |
| 2問目に正解 | HP10回復、カード1枚を追加、カード1枚を削除から1つ | 同じ |
| 3問目に正解 | 常駐ツールかレアカード | 同じ |
| 間違えたら | HP −5、イベント終了 | ペナルティなし、イベント終了 |

- 正解・不正解のどちらでも、解説と対策を見せる。
- 解析コインを1枚使うと「事前調査」ができ、関係のないダミーの選択肢を1つ消して2択にできる。
- 1回のランで同じ問題は出さない。間違えた問題は弱点ノートに記録される。
- TYPE C(攻撃コマンドの選択)は難しめなので使わない。

## 11. カード基地(ランをまたいで残るもの)

ミッション選択画面の「🎴 カード基地」から開く。ブラウザ(localStorage)に保存され、ランをやり直しても消えない。ミッション選択画面の「👤 プレイヤー登録」で名前を登録すると、バックエンド(PostgreSQL)にも保存され、別のブラウザでも続きから遊べる(パスワードは使わない。詳しくは `docs/api-contract.md`)。バックエンドにつながらないときはブラウザだけに保存し、つながったら送る。ランそのものは保存しないので、読み込み直すとランは最初からになる。

- **図鑑**:出会ったカード・敵・解放した進化先
- **弱点ノート**:イベントで間違えた問題の復習。正解すると、次のランの開始時に解析コイン+1(最大3枚まで貯まる)
- **戦績**:プレイ回数、クリア回数、エリート撃破数、クイズの正解数、最高連続正解
- **実績**(6個):ARGUS 撃破、強敵突破、連続診断パーフェクト(3問連続正解)、進化の探求者(進化先を5種類解放)、ツール収集家(12種類以上を図鑑に登録)、弱点克服(復習で1問正解)

   - 帯域3にしたので、帯域+1の常駐ツール(ゼロトラスト鍵・オーバークロックバス)が特に強い(適当に遊ぶボットで勝率+30〜49%)
